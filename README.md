## Qué hago

- **Sistemas administrativos a medida**: usuarios y permisos por rol, inventario, reportes y dashboards KPI.
- **Sitios y portales web** responsivos, optimizados para SEO, con panel de administración.
- **Pagos y facturación**: facturación electrónica SIAT, Stripe, Red Enlace, VeriPago y Multipago (QR y tarjeta).
- **Integraciones y automatización**: WhatsApp Business API, Odoo por API, correo transaccional, tiempo real con WebSockets.
- **Despliegue y DevOps**: servidores Linux, Docker, Nginx, AWS y CI/CD.
